How to use this reference
LIVE schema support is distinct from received values. PTU definitions and historical action names remain reference-only until the active schema and game support them. Simulator values are labeled. Lookup refreshes at most once per second while this tab is visible; it pauses when hidden or minimized. Looking up an input never sends it to the game.

OFF uses the same modifiers as ON. For a toggle binding choose the same key for both. Only a confirmed mismatch sends a command, once per mismatch.
Readouts appear in order, up to six lines on the OLED.
First matching rule wins. Missing or stale data turns the LED off. One WS2812 chain per ESP32, 1–64 pixels with the same rule; share GND and use suitable LED power.

Initial firmware upload
ESP32 firmware is installed once; interface changes use Send interface. Arduino uploads include the saved design and EEPROM settings. DCSBIOSKit: disconnect the powered bus and connect only the slave programmer. Never select the master controller.
